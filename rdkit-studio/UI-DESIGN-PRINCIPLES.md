# 教學工具型網頁的 UI 設計精神

以 RDKit Studio 為範例，整理出可複用於其他「輸入 → 預覽 → 輸出」型教學工具的設計原則。
第 1–5 節是通用原則；第 6–7 節是桌面與手機的具體版面；第 8 節是實作時踩過的陷阱；附錄是本專案的專屬規格。

> 適用對象：同一類型的單頁工具（化學結構繪圖、物理模擬、圖表產生器等），特徵是「左邊設定、中間預覽、下方輸出」。

---

## 1. 核心原則：依「對什麼動作」決定放哪裡

任何控制項只問一個問題：**它改的是分子的畫法、圖上的後製，還是輸出檔？**

| 區域 | 職責 | 內容 | 特性 |
|---|---|---|---|
| **設定區**（桌面在左、手機為底部面板） | 這個內容**長什麼樣** | 輸入、樣式 | 改了會**重繪** |
| **預覽上方工具列** | 對**已畫好的圖**做動作 | 變換、標色 | 不改內容本身，可還原 |
| **預覽下方輸出列** | **輸出** | 尺寸、背景、格式、複製、下載 | 只影響輸出，不影響畫面 |

放錯區是介面難懂的最主要原因。新增任何控制項前，先回答這個問題。

### 例外要明確處理

會改變**內容的意義**的動作，不可放進「不改內容」的工具列。例如「轉為對映異構物」會把 R 變 S，改變了化學意義，因此放在資訊列的立體徽章旁，而不是變換工具列。

---

## 2. 可發現性

1. **常駐，不折疊**：主要工具以按鈕常駐，不藏在 `<details>` 裡。使用者看不到的功能等於沒有。（本專案最初的「標示」就是一個折疊摘要，使用者根本找不到。）
2. **圖示加文字**：工具按鈕兩者並用（🖍 標色）。純圖示只用在全站一致且無歧義的動作。
3. **情境式二層工具列**：第一層常駐，第二層只在該工具啟用時出現（類似 Word 的情境索引標籤）。
4. **模式必須有指示**：進入會改變畫布點擊行為的模式時，要同時有三樣：
   - 按鈕高亮（`aria-pressed`）
   - 游標改變（`crosshair`）
   - 畫布角落提示（「標色中・Esc 完成」）
5. **用不到就停用，不要報錯**：選項清單只列出「目前內容真的有的」。使用者不該靠試誤才發現某個選項不適用。

---

## 3. 漸進式揭露

- 預設只顯示最常用的選項，次要選項在需要時才出現。
- 設定區採手風琴：預設只展開第一個區塊。
- 相關的短選項併成同一列，減少垂直捲動。
- 說明文字放 tooltip（桌面）或可點開的提示（手機），不要常駐佔位。

---

## 4. 即時回饋，減少步驟

- **自動套用**：選好就生效，不設「套用」按鈕。
- 每個動作都要可復原；清除類按鈕用溫和措辭（「清除這個」，而不是「刪除選取」）。
- 狀態訊息放在**畫布浮動提示或狀態列**，不要塞在控制項下方的說明文字裡，那個位置容易被當成裝飾而忽略。

---

## 5. 文案規則

1. **同一個詞只代表一件事**。「標示」曾同時指氫的標示、R/S 標註與上色，已改用「標色」專指上色。
2. **動詞要具體**：不用「選取」「套用」「結束」這類看不出對象的動詞。
3. **避免術語**：不說「清除此選取」，說「清除這個」。
4. **選項名稱不得與區塊標題撞名**：自動佈局的選項是「佈局 A／B」，不叫「樣式 1／2」，因為區塊標題就叫「樣式」。
5. **按鈕文案保持精簡**：補充說明放提示裡。例：標色會一併輸出到圖檔，這句話寫在提示，按鈕只寫「標色」。
6. **領域名詞中文優先、英文輔助**：「羧酸　Carboxylic acid」，不是只給英文。
7. **相同圖示不可代表不同動作**。
8. **標籤要自帶脈絡**：「氫」改為「氫原子」，「甲基」改為「末端甲基」。

## 6. 桌面版（≥ 901px）

### 版面

```
┌ 左欄 ─────────────┐ ┌ 預覽 ────────────────────────────────┐
│ 結構輸入           │ │ 變換 ↺ ↻ ↔ ↕ 重設 │ 🖍 標色           │ 第一層（常駐）
│ ▾ 樣式（手風琴）    │ │ [點選|元素|官能基] [目標▾] ●●●● 清除 完成 │ 第二層（標色時才出現）
│   ▸ 外觀與線條      │ ├──────────────────────────────────────┤
│   ▸ 原子與基團      │ │               畫布                    │
│   ▸ 立體化學與編號   │ ├──────────────────────────────────────┤
└───────────────────┘ │ 名稱 [轉為對映異構物] 分子式 MW 輸出尺寸 SMILES │
                      │ 尺寸 │ 背景 │ PNG SVG │ DPI │ 複製圖片 下載   │
                      └──────────────────────────────────────┘
```

### 規則

- 整頁 `100dvh` 一個螢幕，不捲動；畫布吃掉剩餘高度。
- 畫布上下對稱：上方一條工具列，下方一條輸出列。
- 資訊列（名稱、分子式、MW、輸出尺寸、SMILES）併成一行，夾在畫布與輸出列之間。
- 工具列兩層用 `.canvas-toolbars` 包起來；第二層用 `hidden` 屬性控制顯示。

## 7. 手機版（≤ 900px）

**目標：不要一直上下拉。畫布永遠在畫面內，控制項不佔用畫布空間。**

### 版面

```
┌──────────────────────┐
│ 輸入列：[SMILES…][繪製][歷史] │  單列；快速試用為橫向捲動 chip
├──────────────────────┤
│ 變換 ↺ ↻ ↔ ↕ 重設 │ 🖍 標色 │
│        畫布（常駐）          │  吃掉剩餘高度
│ 名稱 · 分子式 · MW …（橫向捲動）│
├──────────────────────┤
│ ┌ 底部面板（按需開啟）┐       │  position: fixed，坐在動作列上方
│ └──────────────────┘       │
│ [樣式][尺寸與格式] [複製圖片][↓下載] │  動作列（常駐）
└──────────────────────┘
```

### 設計決策

1. **動作列就是原本的輸出列**：`樣式｜尺寸與格式｜複製圖片｜下載`。「下載」永遠在，不必開任何面板。
2. **三種底部面板**，同一時間最多一個：
   - 樣式面板（點「樣式」分頁）
   - 尺寸與格式面板（點「尺寸與格式」）
   - 標色面板（點工具列的「🖍 標色」時自動出現，位於畫布上方的按鈕仍是開關）
3. **面板開啟時畫布縮小讓路**，分子始終看得見，不被蓋住。
4. **面板互斥**：開樣式或輸出面板時，標色面板暫時隱藏（標色模式仍保持），關閉後回復。
5. **Esc 先關面板**，再退出標色。
6. **開面板時收起次要資訊**：輸入區的標題列、快速試用、提示文字暫時隱藏，把高度讓給畫布。
7. **選項用單列橫向捲動的 chip**，資訊列用橫向捲動，不用換行堆疊成長列。
8. **面板內顯示標籤文字**（尺寸、背景），因為手機沒有 hover 提示可看。

### 與最初規劃的差異

最初草案是 `樣式｜標色｜變換｜輸出` 四個底部分頁。實作時改為：**變換與標色留在畫布上方工具列**（已經是一列、且和畫布操作最近），底部只放需要大空間的「樣式」和「尺寸與格式」。理由：避免同一功能出現兩個入口。

### 觸控友善

- 所有可點元素最小 44px 高。
- **不得依賴 hover 與 `title`**：手機看不到。關鍵說明要直接顯示，或用可點開的提示。
- 避免需要精準點擊的小圖示。

### 尚未完成

- 許多說明仍寫在 `title` 提示裡，手機看不到。需要改成「？」點開的小浮層，或直接顯示的輔助文字。

## 8. 實作陷阱（都是實際踩過的）

### 手機單螢幕版面

- **固定定位的面板，位置要量出來，不要寫死**。`--bar-h` 必須是「動作列頂端到螢幕底部的距離」（`innerHeight - actionBar.getBoundingClientRect().top`），不是動作列自己的高度。動作列下方還有 padding 與留白，用列高會讓面板蓋住按鈕。
- **面板高度要回報給畫布**：用 `--sheet-h` 讓畫布 `margin-bottom` 讓位；用 `ResizeObserver` 與 `MutationObserver`（監看 `hidden`）保持同步。
- **量測不能只靠 `requestAnimationFrame`**：背景分頁或被節流時 rAF 不一定執行，會留下過期數值。先同步量一次，再 rAF 補量一次。
- **`<details>` 當面板**：用 JS 控制 `open`，並讓 `summary` 在手機隱藏或轉成分頁按鈕；內容由 CSS 改成 `position: fixed`。
- **`hidden` 屬性會被 `display:flex` 蓋過**：元素若自己設了 `display`，`hidden` 就失效，要確認有全域 `[hidden]{display:none!important}` 或用 `:not([hidden])` 限定。
- **留白會累加**：`main`、`.workspace-grid`、面板各自有 padding，疊起來底部多出 30px。逐層量，不要猜。
- **鍵盤彈出**：`100dvh` 會縮，畫布設 `min-height` 並讓外層 `overflow-y:auto` 作為備援，寧可可捲動也不要裁切。
- **旋轉或視窗改變**：切回桌面時要重設 `open` 與 `data-sheet`，但尊重使用者已展開的狀態。

### 資料與選項

- **清單要依內容產生**：選項只列偵測到的項目並附數量，不要列全部再報錯。
- **領域名詞表集中管理**：把中文名放在資料結構裡（`zh` 欄位、`elementName()`），不要散落在畫面字串中。冷門項目要有退路（退回符號）。

### 輸出尺寸：固定高度不等於填滿高度

「固定高度」只保證**畫布**高度，不該保證分子**填滿**畫布。若把圖裁到分子實際範圍再放大到指定高度，扁平的分子（隱藏氫的 C=O、CO₂、HCl）高度趨近零，會被放大到鍵長達整個畫布的數倍，畫布也變得極寬。

做法：**美術範圍的高度至少為 2 個鍵長**（`MIN_ART_HEIGHT_IN_BONDS`，位於 `renderer.js`）。理由：

- 苯環本身約 2 個鍵長高，所以一般的環、長鏈完全不受影響。
- 只有更扁的分子才會被補上留白，分子置中，鍵長不超過畫布高度的一半。
- 不用「限制長寬比」：長寬比反映不出鍵的大小。

鍵長從 SVG 中最長的雙點 `path[class*="bond-"]` 量測，量不到時不套用限制。

### 覆蓋層與抽屜

- 全螢幕抽屜（範例庫）的層級必須**高於**所有底部面板與遮罩；底部面板用 z-index 25，遮罩 29，抽屜 30。
- 開抽屜時自動收起底部面板，避免面板從抽屜旁露出；Esc 優先交給最上層的覆蓋物（抽屜 → 面板 → 標色）。
- 手機上的關閉鈕與其他可點元素同樣要 ≥ 44px。
- 抽屜裡的長篩選列（分類 chip）在手機上改為單列橫向捲動，把垂直空間留給內容。

### 兩份副本的維護

專案同時有「部署版」與「專屬專案」時，**以一份為準、整份複製**，不要兩邊各改一次。測試只放在專屬專案，複製後在那裡更新一次。

### 測試

- 視覺驗證用 headless 瀏覽器透過 DevTools Protocol 操作：畫分子、開面板、截圖、讀版面數值。
- **行動模式模擬（`mobile:true`）在 headless 下會讓固定定位的基準與 `100dvh` 不一致**，截圖底部被裁掉。驗證版面用 `mobile:false` 加上相同寬度。
- **每次截圖後要重新設定視窗尺寸**，否則視窗高度被重置，後續量到的數字都是錯的。
- 載入完成要等待實際的就緒條件（載入畫面消失、關鍵元素存在），不要用固定秒數。
- 測試用的瀏覽器設定檔每次約 30 MB，跑完要刪，否則會把磁碟塞滿。

### 其他

- 修改既有檔案的換行（CRLF／LF）要與原檔一致，否則 diff 會變成整檔變動。

## 9. 檢查清單（新增或修改控制項時）

- [ ] 它改的是畫法、後製，還是輸出？是否放在對應區域？
- [ ] 使用者不需要展開任何東西就能發現它嗎？
- [ ] 如果是模式，有高亮、游標與畫布提示嗎？
- [ ] 選項是否只列出目前內容「可用」的？
- [ ] 文案有沒有和既有詞彙撞名？動詞夠具體嗎？
- [ ] 領域名詞有中文嗎？
- [ ] 桌面：畫布與輸出列是否同時可見？
- [ ] 手機：整頁不捲動？畫布始終在畫面內？面板有沒有蓋住動作列？
- [ ] 手機：不依賴 hover／title？觸控目標 ≥ 44px？
- [ ] 兩份副本是否都已同步，測試是否已更新？

## 附錄 A：本專案的專屬規格

### 標色功能

- 位置：預覽上方工具列，按鈕「🖍 標色」，與「變換」同層。
- 啟用後展開第二層：`[點選原子或鍵｜依元素｜依官能基]　[目標 ▾]　[哪一個 ▾]　● ● ● ●　清除這個　清除全部　完成`
- 目標下拉**只列出此分子偵測到的項目**並附數量（例：「羧酸　Carboxylic acid ×1」）。
- 分子沒有任何可辨識官能基時，停用「依官能基」，tooltip 說明。
- 選好目標後**自動套用**；切換色票、範圍也立即套用。
- Esc 或「完成」退出標色，標記保留。
- **標色會一併輸出到 PNG／SVG**（已驗證：下載與複製、300／600 DPI、透明／白底皆含標色，顏色對應所選色票）。此事寫在提示文字，不寫進按鈕。

### 已定案用語

| 項目 | 用語 |
|---|---|
| 上色功能 | **標色** |
| 方式 | **點選原子或鍵**／依元素／依官能基 |
| 結束 | **完成**（支援 Esc） |
| 清除 | **清除這個**、**清除全部** |
| 範圍 | **哪一個** |
| 自動佈局 | **佈局 A**／**佈局 B** |
| 輸入說明 | **找不到 SMILES？** |
| 快速範例列 | **快速試用** |
| 原子列標籤 | 氫原子／碳原子／末端甲基 |
| 立體鍵 | 楔形鍵／楔形＋R/S／只標 R/S／不標立體 |
| 輸出尺寸 | 輸出 7.58 × 6.90 cm |
| 複製按鈕 | **複製圖片**（附文字） |
| 對映異構物 | **轉為對映異構物** |
