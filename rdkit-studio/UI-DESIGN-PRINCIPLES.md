# RDKit Studio UI 設計精神

本文件記錄介面的放置邏輯、文案規則與手機版原則。新增或調整任何控制項前，先對照本文件。

---

## 1. 核心原則：依「對什麼動作」決定放哪裡

| 區域 | 職責 | 內容 | 特性 |
|---|---|---|---|
| **左側** | 這個分子**長什麼樣** | 結構輸入、樣式設定 | 改了會**重繪** |
| **畫布上方** | 對**已畫好的圖**做動作 | 變換、標色、轉對映異構物 | 不改化學內容的後製；可還原 |
| **畫布下方** | **輸出** | 尺寸、背景、格式、解析度、複製、下載 | 只影響輸出，不影響畫面 |

判斷方式：問「這個控制項改的是分子的畫法、圖上的後製，還是輸出檔？」答案決定它放哪一區。放錯區是介面難懂的主要原因。

### 例外要明確處理

- **「⇌ R↔S」不是變換**：它把分子變成對映異構物，改變化學意義。不放在變換工具列，改放資訊列的立體徽章旁，標為「轉為對映異構物」。

---

## 2. 可發現性

1. **常駐，不折疊**：主要工具以按鈕常駐在工具列，不藏在 `<details>` 裡。使用者看不到的功能等於沒有。
2. **圖示＋文字**：工具按鈕兩者並用（例如 🖍 標色）。純圖示只用於全站一致且無歧義的動作。
3. **情境式二層工具列**：第一層常駐 `變換｜標色｜`；第二層只在該工具啟用時才出現（類似 Word 的情境索引標籤）。
4. **模式要有指示**：進入「標色」這類會改變畫布點擊行為的模式時，必須同時有：
   - 按鈕高亮（`aria-pressed`）
   - 游標改變
   - 畫布角落提示「標色中・Esc 完成」
5. **用不到就停用，不要報錯**：只列出此分子「有的」選項，不讓使用者選了才得到「找不到」。

---

## 3. 漸進式揭露

- 預設只顯示最常用的選項，次要選項在需要時才出現。
- 「標色」預設只有一排：`[點選｜元素｜官能基]` ＋ 色票；選了元素或官能基，才多出目標下拉。
- 左側「樣式」採手風琴式，預設只展開第一個區塊；展開狀態可記住。
- 相關的短選項**併成同一列**（例如顏色＋鍵粗、氫＋碳＋甲基），減少垂直捲動。

---

## 4. 即時回饋，減少步驟

- **自動套用**：標色選好目標就立刻上色，不設「套用」按鈕。
- 每個動作都可復原：提供「清除這個」「清除全部」，不使用帶有破壞感的措辭。
- 狀態訊息放在**畫布浮動提示或狀態列**，不要塞在控制項下方的說明文字裡（容易被當成裝飾而忽略）。

---

## 5. 文案規則

1. **同一個詞只代表一件事**。例如「標示」曾同時指氫的標示、R/S 標註與上色，已改用「**標色**」專指上色。
2. **動詞要具體**：不用「選取」「套用」「結束」這類看不出對象的動詞。
3. **避免術語**：不說「清除此選取」，說「清除這個」。
4. **選項名稱不得與區塊標題撞名**：自動佈局的選項是「佈局 A／B」，不再叫「樣式 1／2」（與區塊標題「樣式」衝突）。
5. **按鈕文案保持精簡**：說明性內容放 tooltip 或提示，不寫進按鈕。
   - 例：標色會一併輸出到圖檔，這件事寫在提示裡（「標色會一併輸出」），按鈕只寫「標色」。
6. **中文優先，英文輔助**：教學對象是高中生，化學名詞一律附中文（見第 7 節）。
7. **相同圖示不可代表不同動作**：「⧉」不要同時用於複製公式、SMILES、圖片，各自用文字標籤區分。

### 已定案用語

| 項目 | 用語 |
|---|---|
| 上色功能 | **標色** |
| 方式 | **點選原子或鍵**／依元素／依官能基 |
| 結束 | **完成**（支援 Esc） |
| 清除 | **清除這個**、**清除全部** |
| 範圍 | **哪一個**（全部 ×3／第 1 個） |
| 自動佈局 | **佈局 A**／**佈局 B** |
| 輸入說明 | **找不到 SMILES？** |
| 原子列標籤 | 氫原子／碳原子／末端甲基 |
| 立體鍵 | 楔形鍵／楔形＋R/S／只標 R/S／不標立體 |
| 輸出尺寸 | 輸出 7.58 × 6.90 cm |
| 複製圖片 | **複製圖片**（附文字） |

## 6. 標色功能規格

- 位置：畫布上方工具列，按鈕「🖍 標色」，與「變換」同層。
- 啟用後在下方展開第二層：

```
[點選原子或鍵｜依元素｜依官能基]  [目標 ▾]  [哪一個 ▾]  ● ● ● ●   清除 ▾   完成
```

- 目標下拉**只列出此分子偵測到的項目**，並附數量，例如「羰基 ×1」；沒有的不列。
- 若分子沒有任何可辨識的官能基，停用「依官能基」並以 tooltip 說明。
- 選好目標後自動套用，不設「套用」按鈕。
- 「清除」合併為下拉：清除這個／清除全部。
- 標色會一併輸出到 PNG／SVG，提示文字寫「標色會一併輸出」。

## 7. 化學名詞中文對照

官能基下拉格式為「**中文　English**」，中文在前。

| id | 顯示 |
|---|---|
| alcohol | 醇（羥基）Alcohol |
| phenol | 酚 Phenol |
| aldehyde | 醛 Aldehyde |
| ketone | 酮 Ketone |
| carboxylic-acid | 羧酸 Carboxylic acid |
| ester | 酯 Ester |
| amide | 醯胺 Amide |
| amine | 胺 Amine |

元素下拉格式為「**碳 C**」，使用台灣通行的元素中文名；清單來自分子內實際有的元素，沒有中文名的（極少見的）退回只顯示符號。

## 8. 手機版原則

目標：**不要一直上下拉**。手機上畫布永遠在畫面內，控制項不佔用畫布空間。

1. **單螢幕工作區**：版面高度用 `100dvh`，頁面本身不捲動；只有面板內部可捲動。
2. **畫布固定在上方**，約占可用高度的 40–50%，平時不被控制項擠掉。
3. **底部分頁列＋底部面板（bottom sheet）**：

```
┌──────────────────────┐
│ 輸入列：[SMILES…][繪製] │  單列
├──────────────────────┤
│                      │
│        畫布（常駐）      │
│                      │
├──────────────────────┤
│ 面板內容（半高，可收合）  │  點分頁才展開
├──────────────────────┤
│ 樣式 │ 標色 │ 變換 │ 輸出 │  底部分頁列
└──────────────────────┘
```

   - 點分頁列開啟對應面板；再點一次或下滑收合。
   - 面板開啟時畫布仍可見，使用者能即時看到變化。
4. **選項用單列橫向捲動的 chip**，不換行堆疊成長列。
5. **標色**：面板內第一層為方式與色票，目標用橫向 chip；畫布上的原子與鍵命中區至少 44px。
6. **輸出**：「↓ 下載」固定在底部分頁列旁，不必打開面板就能下載。
7. **資訊列精簡**：預設只顯示名稱與分子式；MW、SMILES、來源收進「更多」。
8. **觸控友善**：
   - 所有可點元素最小 44×44px。
   - **不要依賴 hover／title 提示**：手機看不到。重要說明要用「？」點開的小浮層或直接顯示的輔助文字。
   - 避免需要精準點擊的小圖示。
9. **斷點**：900px 以下用手機／平板直式版面；平板橫向（≥901px）沿用桌面版。

## 9. 檢查清單（新增或修改控制項時）

- [ ] 它改的是畫法、後製，還是輸出？是否放在對應區域？
- [ ] 使用者不需要展開任何東西就能發現它嗎？
- [ ] 如果是模式，有高亮、游標與畫布提示嗎？
- [ ] 選項是否只列出此分子「可用」的？
- [ ] 文案有沒有和既有詞彙撞名？動詞夠具體嗎？
- [ ] 化學名詞有中文嗎？
- [ ] 手機上看得到、點得到、不需 hover、不擠掉畫布嗎？
