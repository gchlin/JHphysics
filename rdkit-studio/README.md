# RDKit SVG Studio（GitHub Pages 版本）

此目錄是主網站首頁連結的靜態部署副本。`index.html`、`styles.css`、`script.js`、`name-lookup.js`、`renderer.js`、`compound-aliases.json` 與範例圖檔來自 `../RDKit/RDKit/`；RDKit.js 2025.3.3-1.0.0 的 JavaScript、WebAssembly 和授權文件存放於 `vendor/`。「自動佈局」以「樣式 1／樣式 2」切換 CoordGen 與 RDKit 原生排版；滑過控件可查看乙醚和氫顯示的比較提示。

編號選單提供按需查詢的「IUPAC 母體碳」模式，可微調已標示母體碳的標籤；SMILES 旁的 OpenClatura 連結開啟服務首頁，需手動複製與貼回查詢。整合範圍及尚待瀏覽器驗收項目見 [`../RDKit/OPENCLATURA-IUPAC-TEST-REPORT.md`](../RDKit/OPENCLATURA-IUPAC-TEST-REPORT.md)。

頁面提供旋轉、化學組態保真的鏡射、立體標註、SVG 與 300/600 DPI PNG。立體鍵可選楔形鍵、楔形鍵加文字、文字，或不顯示楔形鍵與文字的一般線條。鏡射前後會核對 RDKit 的 R/S 和 E/Z 標記。ACS 預設僅作樣式參考；芳香環圓圈和 PDF/EPS 尚未實作。形式電荷始終顯示。

編號可選 RDKit 原子索引或膽固醇型固醇的類固醇 C 編號。後者比對碳骨架後標示 C1–C27，支鏈延長時可標至 C29；無法可靠辨認時會顯示錯誤。範例庫有膽固醇、β-穀固醇及麥角固醇。兩種編號都可選文字大小：預設「小」比 RDKit 原生索引字大，「中」與元素符號一樣大，「大」為元素符號的 1.25 倍。編號規則與範例來源見原始專案 `../RDKit/RDKit/README.md`。

圖像樣式分成外觀與線條、原子與基團、立體化學與編號三組。桌面預設展開；手機預設收起樣式與尺寸／格式設定，讓圖像優先顯示，旋轉與鏡射仍直接可操作。「教學模式」顯示 C、CH、CH₂、CH₃ 與非碳上的氫，使用粗線，不展開全部氫，也不開啟編號。「原子序號」是從 0 開始的 RDKit 內部識別序號，非命名編號；可展開編號說明。切換預設會同步氫與甲基按鈕。自動佈局的兩種樣式切換 CoordGen 與 RDKit 原生排版；不顯示編號時大小選項禁用。底部輸出區將尺寸、背景、格式、DPI 與匯出控制排列在同一列，數值欄可直接輸入；下載流程不變。SVG 以 cm 寫入實際尺寸且隱藏 DPI，PNG 依寬高輸出像素並標記 300/600 DPI。實作方法與跨程式貼上的限制見 [尺寸控制筆記](SIZING-NOTES.md)。

從儲存庫根目錄執行 `python -m http.server 8000`，開啟 `http://127.0.0.1:8000/rdkit-studio/` 即可在本機使用。發布 GitHub Pages 時，此目錄須與首頁一同提交。

## 名稱、示性式與分子式對照

「繪製」旁的「歷史」保留最近 30 個成功結構，依 SMILES 去重。使用瀏覽器 localStorage，重新整理或下次開啟同一網站仍可載入；點選後以保存的 SMILES 在本機重繪，不重查名稱 API。可清除歷史；儲存被禁用、損壞或容量不足時會提示改用本頁記憶體。歷史及來源資料不代表再次驗證化合物名稱，R↔S 反轉不沿用原查詢來源。

SMILES／Gemini 求助的可重跑檢查與手動邊界案例見 [求助測試指南](SMILES-HELP-TESTING.md)。

畫布下方的分子式按鈕會複製 MathML（同時提供 HTML 與純文字剪貼簿格式），供 Microsoft 365 Word 直接貼成可編輯公式；其他純文字編輯器可能顯示 MathML 標記。

尺寸有兩種模式：預設的「固定高度」將畫布鎖定為 2、5、10 cm 或自訂高度，寬度依圖形邊界自動計算；「固定鍵長」則讓不同分子的鍵、文字與線寬使用相同實體比例，畫布寬高隨分子伸縮。固定鍵長的 100% 以 0.508 cm 鍵長為基準，參考 [ACS 圖稿規格](https://researcher-resources.acs.org/publish/author_guidelines/pdf?coden=ansadg)；40% 與 200% 分別按比例縮放。SVG 寫入實體 cm，PNG 依 300 或 600 DPI 產生像素並寫入 `pHYs` 密度資訊。Word／PPT 若將圖片放在行內，段落仍會依圖片高度調整行高；固定高度能讓不同分子的佔位一致。

「複製 PNG」會同時提供原始 PNG 與標示 cm 尺寸的 HTML 圖片，因為瀏覽器的圖片剪貼簿可能移除 PNG 的 `pHYs`。下載的 PNG 檔保留 `pHYs`；貼上時實際採用哪種剪貼簿格式仍由 Word／PPT 決定。

`compound-aliases.json` 是優先查詢的本機資料。每筆化合物包含穩定的 `id`、中文 `name`、`english`、`formula`、可交給 RDKit 的 `smiles`，以及其他名稱 `names` 和示性式 `condensed`。這是**精確對照表**，不是通用的示性式語法解析器。新增條目時，應核對結構、分子式及立體組態；俗名若指混合物或範圍不明，不應直接對到單一 SMILES。

目前收錄 182 筆，涵蓋高中常見的酸鹼、沉澱鹽、氧化還原試劑、芳香族衍生物、高分子單體、醣類、胺基酸與核酸鹼基；範例庫有 62 筆。選取範圍參考[普通型高中自然科學領域課程綱要](https://stv.naer.edu.tw/data/course_outline/pta_18538_240851_60502.pdf)，結構參照 [ChEBI](https://www.ebi.ac.uk/chebi/) 並以 RDKit 核對可解析性、分子式與手性中心。這是便於繪圖的常用清單，並非完整化學物質庫。離子化合物以**化學式單位的分離離子**繪製，不表示實際晶格；溶液名稱（如鹽酸、氨水）、組成不定的材料與網狀固體不直接映射成單一分子。

`concepts` 收錄三酸甘油酯、澱粉、纖維素、糖原及常見高分子等**沒有唯一 SMILES** 的查詢詞，輸入時會提示使用者選擇具體分子、單體或片段。例如「麥芽糖」可展示澱粉中的 α(1→4) 鍵結片段，但不能代表完整澱粉。`K2Cr2O7` 是**二鉻酸鉀**，過二硫酸鉀則是 `K2S2O8`；兩者分開收錄。未指定手性的胺基酸與天然 L 型分開列出，避免從一般名稱推定唯一立體組態。新增糖類採特定開鏈形或未指定還原端異頭碳的環狀形，名稱會標明。

輸入列的「不知道 SMILES？」提供包含目前輸入的查詢提示詞，以及獨立的「開啟 Gemini」連結。複製提示詞後自行貼到 Gemini，再將回覆的 SMILES 貼回繪圖；頁面不會自動帶入 Gemini。線上名稱查詢失敗或未收錄分子式也提供複製入口。AI 可能辨認錯誤，仍須核對異構物、電荷與分子式；有歧義時先選候選，再繪圖。繪製成功不代表已確認是目標化合物。

```json
{"id":"ethanol","name":"乙醇","english":"Ethanol","formula":"C2H6O","smiles":"CCO","names":["酒精","Ethyl alcohol"],"condensed":["CH3CH2OH","C2H5OH"]}
```

查詢次序為：本機對照表的分子式／示性式與名稱、既有範例庫，最後將輸入交給 RDKit 當作 SMILES。**分子式即使只找到一筆，也要求使用者確認**，因為本機對照表不保證收齊所有異構物；若有多筆，例如 `C2H6O` 對應乙醇和二甲醚，會顯示結構讓使用者選。候選只代表目前已收錄的化合物。若輸入同時是有效 SMILES 且代表不同結構，例如 `CO` 可表示甲醇的 SMILES 或一氧化碳的分子式，也會要求選擇。只有使用者選定後才繪圖與匯出。

常用中文名與英文名在本機採不分大小寫的精確比對；分子式和示性式以元素大小寫為準，也接受下標數字及空白。本機未命中時先用 RDKit 解析，合法 SMILES 直接繪圖。解析失敗且符合保守純分子式辨識（有效元素 token 且含數字）時，請使用者指定名稱或結構，不送名稱服務；此辨識並非完整分子式／示性式語法解析器。

其他未收錄名稱在按「繪製」後，會以保留內部空白及大小寫的文字依序查詢 [OPSIN](https://www.ebi.ac.uk/opsin/) 與 [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/pcfe/docs/markdown/pug-rest.md)。每個服務約 8 秒逾時，不自動重試；修改輸入或再次繪製會取消舊查詢。最多快取 50 個成功查詢於本次頁面記憶體，重新整理即清空；網路錯誤不快取。PubChem 請求至少間隔 250 ms。

所有採用的回傳 SMILES 均先經本機 RDKit 解析。OPSIN 成功可直接繪製，WARNING 須先確認；PubChem 一律先顯示回傳 IUPAC 名、分子式與 CID 候選，即使只有一筆，避免同名查詢誤選酸鹽或質子化型態。最多列 8 筆並提示範圍限制，並非全部異構物。PubChem 使用包含立體與同位素資訊的 `SMILES`，不以不含立體資訊的 `ConnectivitySMILES` 替代。成功繪製後，資訊列右側顯示最多 25 字元的 SMILES 預覽，旁有複製按鈕；R↔S 反轉後會更新為新結構。查詢來源以單一連結核對；回傳可解析不等於名稱語意已驗證。中文名稱不保證被外部服務收錄，未找到、逾時／網路、限流與格式錯誤會分別提示，可再用 Gemini 求助。

## 教學標色（第一階段）

預覽上方只有一個「標示」入口。展開後可直接點選原子或鍵，也可用元素或官能基預選，再選固定顏色並按「套用」。官能基可選全部或第幾個；藍色虛線／半透明預覽只表示目前選取，套用後才寫入匯出圖。可用「清除此選取」移除局部標色，或「全部清除」重設；「結束」收起工具列，保留已套用的顏色。元素與官能基以隨附 RDKit 的完整分子索引辨識，不需輸入 SMARTS。

目前支援醇羥基、酚羥基、羧基、酯基、醛基、酮羰基、醯胺與一般胺；未找到所選基團時會提示。此階段不包含環辨識、基團縮寫與反應式。點選範圍包含骨架碳，且比細鍵寬；可用 Tab 與 Enter／空白鍵操作。

旋轉、鏡射、尺寸、排版與編號調整保留標色與選取。同一個繪圖分子同時核對 RDKit canonical isomeric SMILES 與原始 SMILES；換分子、原子排列不同的等價 SMILES 或反轉立體組態會清除並提示。變更氫顯示模式時會清除並提示，避免展開／收合後索引錯置。標示僅保存在目前頁面，不寫入歷史紀錄或 localStorage。

SVG、PNG 與複製共用含套用標色的 SVG；互動命中範圍、鍵盤焦點與候選預覽不進入匯出。透明 RDKit 原子幾何用於建立精確點選範圍，匯出中保留不可見的原子幾何，不含事件或操作 overlay。

## 結構微調與母體教學

- 「微調結構」會開啟三步提示：複製目前 SMILES、前往 OpenClatura 新頁貼上修改，再複製修改後 SMILES 回本頁輸入框並按「繪製」。
- 選擇「IUPAC 碳編號」後，可切換「C1、C2」或「C ＋ 數字旁註」。後者只在母體碳顯示 C，保留自訂文字；標準 C1 等標號改顯示數字。
- 開啟標色工具後按「主鏈標色」，會按需向 OpenClatura 取得並驗證母體主鏈／主環，包含母體內的非碳原子及相連鍵。再按同一按鈕可單獨清除；手動標色優先顯示且會保留。查詢失敗不影響普通繪圖與手動標色。換分子或氫模式時清除標色；目前只支援 API 可完整驗證的單一母體，並需網路服務可用。

IUPAC 原子 ID 注意：API 的 graph ID 可能不同於處理後 SMILES 的 RDKit 解析索引。程式要求完整 atom-id 標記並驗證唯一、全原子對照後才套號；不完整或矛盾資料會安全拒絕。咖啡因已用真實 API 回應及本機 WASM 回歸，顯示 C2、C4、C5、C6、C8（母環的其他定位號由 N 佔用）。
