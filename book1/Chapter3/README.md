# 第一冊第三章：牛頓第二運動定律動畫紀錄

## 本次建立內容

依照 `ref/4-3牛頓第二運動定律-SUPER講義ppt` 的投影片，建立 8 個例題動畫：

1. `example1.html`：單一物體受力（一維）——下降逃生、繩張力上限。
2. `example2.html`：單一物體受力（二維）——斜向拉力分解與正向力。
3. `example3.html`：等加速度車內的擺錘——`a = g tanθ`。
4. `example4.html`：阿特伍機——整數質量模型、定滑輪、繩、A／B 物體與必要向量。
5. `example5.html`：光滑固定斜面——37°、53° 雙斜面系統。
6. `example6.html`：連結體——2 kg、3 kg、1 kg 三方塊。
7. `example7.html`：光滑可移動斜面——木塊與斜面相對靜止。
8. `example8.html`：動滑輪——繩長約束與 `T₂ = 2T₁`。

## 設計與實作

- `chapter3.js` 集中處理 Canvas 繪圖、動畫播放／暫停／重置、速度選擇與 8 個例題的場景。
- `chapter3.css` 提供例題列表、動畫頁、控制列與手機版面。
- 每個例題使用 `960 × 540` 邏輯場景，顯示時使用單一 `scale = min(W / 960, H / 540)`，避免手機橫向工具列造成圖形變形。
- Canvas 像素尺寸依實際顯示尺寸乘上有效 DPR 設定，DPR 上限為 2。
- 動畫使用 `requestAnimationFrame`；頁面切到背景時會自動暫停。
- 受力箭頭、分力、加速度、繩張力與主要答案直接顯示在動畫或右側解題關係中，方便對照講義。

### example4 特別規格

- 來源：`阿特午ex4.png`，重點是上方支架、直桿、中央定滑輪、左右兩端物體與兩側向上的張力箭頭。
- 觀察目標：看見同一條不可伸長細繩使 A、B 反向移動，且兩端位移大小相同；調整質量後比較運動方向與平衡狀態。
- `mA`、`mB` 為 1–20 kg 的整數控制，預設為 6 kg、4 kg；動畫依理想阿特伍機模型由靜止開始單向加速。
- 質量相等時兩物體保持靜止；質量不等時播放至安全位移後停止，不自動反向。
- 動畫只保留參考圖必要的 `T` 與支點支持力 `F`，不加入公式、重力箭頭、儀表板或額外圖表。
