如何判讀

  1. fetch 成功：可從 GitHub Pages 網頁讀取回應，表示目前測試的 Origin、端點和請求條件下跨網域存取可用。
  2. 包含 IUPAC 名稱：證明能命名，但還不能證明可在你自己的分子圖上標注 C1、C2……。
  3. 包含 atom-to-locant 對照：需確認原子索引與你原本 RDKit.js 的 atom index 相符；如果 SMILES 在中途被重新解析或正規化，索引未必一致。
  4. 只有文字描述定位號：代表仍需要可靠的結構化輸出介面，不能直接把文字當成正式原子映射。
