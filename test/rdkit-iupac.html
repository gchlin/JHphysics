測試案例

原需求中 CC(C)CC(=O)O 標成 4-methylpentanoic acid，但實際結構是 3-methylbutanoic acid（3-甲基丁酸）。表格保留原始輸入並另列經 API 確認的 4-methylpentanoic acid SMILES CC(C)CCC(=O)O。

等待 RDKit.js 載入。
輸入 SMILESAPI 名稱／預期名稱API 處理後 SMILESAPI 主體定位號 → Atom ID原始輸入索引相容性圖形預覽操作

本頁判讀方式

  1. API 的 `paragraphs` 會提供 Processed SMILES 與該字串的 Atom IDs；API 定位號索引以這個處理後字串為準。
  2. 把相同 Processed SMILES 交給 RDKit.js 解析，並檢查原子數、元素及主鏈相鄰關係；標號 SVG 也由這個 RDKit.js 分子產生。
  3. 若 API 索引不能沿著原始輸入 RDKit 分子的鍵連成主體路徑，頁面會標示原索引不相容，不能直接套在 GUI 原始分子上。
  4. 只有瀏覽器顯示 HTTP 成功、解析 JSON、定位號表與圖形標號時，該案例才算完整通過。跨網域失敗會保留瀏覽器實際錯誤。
